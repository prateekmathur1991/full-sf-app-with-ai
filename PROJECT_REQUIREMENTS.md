### A Custom Quote Management Screen

Your job is to build a custom quote management screen for a Salesforce customer not paying for the Salesforce CPQ license. You need to ensure that the right custom objects for Quote, Quote Line etc are there for the customer.

#### Requirements

1. Create an LWC that allows users to create and manage quotes. This LWC should have a table of quote lines, and a header section that should display agreegates of the quote lines. The following calculations should show on the header with aggregates - total list price, total negotiated price, total discount, and discount percentage.

2. On every quote line, user should be able to add the list price, negotiated price, total discount, and discount percentage.

3. Users should be able to create, read, update, and delete quote lines.
