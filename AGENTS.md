# Project Overview
This is a Salesforce DX project called 'Full Salesforce App with AI'. The project is meant to be a result of using AI coding tools to generate a Salesforce project of medium complexity, and learning how AI coding agents can help in developing Salesforce applications.

# Repository Overview
The repository follows standard Salesforce SFDX project structure. All metadata is housed in the `force-app/` folder, with relevant folders for each metadata type.

# Testing Requirements

1. All apex code you create or modify should have test class coverage. Test class coverage should not be just for the sake of providing test coverage, but should actually assert the business logic written in the code.
2. All apex classes should have minimum 85% of code coverage.
